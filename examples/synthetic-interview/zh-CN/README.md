# AI Synthetic Test: Complete Realistic Interview (AI 合成测试)

This directory records a complete interview validation run between an independent AI interviewer and an independent AI candidate, with a mediator forwarding each actual turn verbatim. The JD, company, resume, project, and candidate capabilities are synthetic. They do not describe real people, employers, or hiring outcomes.

## Language conventions

The test documentation (`README.md` and `validation.md`) is in English so the same reporting structure can support interviews in different languages. Each run's input materials, raw conversation, and final interview report retain their actual language.

**This run's interview language: Simplified Chinese (`zh-CN`).** The results below describe this Chinese-language run only. English, Japanese, or other language runs should record their own language and evidence separately; they must not overwrite or translate this run's original records as if those were newly executed tests.

## Archive location

All artifacts for this Chinese-language run are now stored under `examples/synthetic-interview/zh-CN/`. See the [language index](../README.md) for other executed runs.

Original agent tasks, transcripts, reports, and execution records retain the paths used when the interview actually ran, before this folder was introduced. Those historical path strings have not been rewritten. Paths in the artifact map below are relative to this run directory. For a new execution, use a separate run directory and adapt paths in new task copies rather than editing these archived inputs.

## Execution boundaries

- Both role agents were created with `fork_turns="none"`, without inheriting the development conversation.
- The interviewer was instructed to read only the isolated installed Skill's runtime resources, interview request, JD, resume, and project facts, excluding the candidate capability profile and validation conclusions.
- The candidate received the synthetic JD, resume, project facts, capability profile, and actual interviewer messages, excluding the Skill, scoring rules, expected scores, and validation conclusions.
- The mediator forwarded and recorded actual messages without inventing answers or changing ratings to obtain an expected result.
- Raw dialogue, the final report, and validation conclusions are stored separately. Prepared materials alone are not execution evidence.
- The tested Skill was installed in an isolated directory here, without replacing a personal installation. This validates explicit loading by installed path, not global automatic discovery.

## Artifact map

- `inputs/`: synthetic materials and agent tasks.
- `installed-skills/interview-skill/`: historical local installation, not published or required for public replay.
- `exchanges/`: original output from each agent turn.
- `transcript.jsonl`, `transcript.md`: raw dialogue in actual chronological order.
- `final-report.md`: the final report actually generated by the interviewer.
- `evidence/`: frozen standards, scoring inputs, script execution records, and independent arithmetic checks.
- `run-metadata.json`: versions, agents, dates, and execution environment. Unknown fields remain marked as not recorded (`未记录` in the original metadata).
- `validation.md`: checks, findings, limitations, and untested scenarios.

Completed on 2026-10-19: 6 main questions, 4 follow-ups, 1 candidate question for the interviewer, and a final report, comprising 23 interview messages. The report, two actual scoring-script executions, and an independent recalculation agree on a score of 63.75 and dimension coverage of 100%.
