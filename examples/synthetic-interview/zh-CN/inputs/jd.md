# AI 合成测试：岗位 JD

所有公司、岗位和业务均为虚构。

公司：北辰协作实验室（合成公司）。
岗位：Python 后端开发工程师。
目标经验：2 年；面向 1–3 年后端经验。

## 业务与职责

维护面向多个企业租户的工单协作平台，为工单查询、状态流转和后台任务提供 API。

- 使用 Python、FastAPI、SQLAlchemy 和 PostgreSQL 开发与维护 REST API。
- 实现租户数据隔离、参数校验、错误处理和工单状态并发更新。
- 根据查询条件设计或使用数据库索引，理解分页、事务及基本的执行计划分析。
- 使用 Redis 缓存热点查询，分析缓存与数据库的一致性风险。
- 通过 pytest 测试关键路径和异常路径，借助结构化日志定位 API 故障。
- 和产品、前端及测试人员澄清业务约束，参与代码评审；合并前需要评审和自动化测试。

## 工作要求

能解释自己负责功能的实现依据与取舍，能在问题出现时提出可验证的排查方法。重视数据正确性和租户隔离，不把依赖故障伪装成业务成功。

技术栈：Python 3.10+、FastAPI、PostgreSQL、Redis、pytest、Docker。

薪酬、值班、加班、团队规模和入职培养安排未提供。
